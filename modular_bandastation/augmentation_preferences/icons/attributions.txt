Changes: selected the independent hand and foot states and fitted them to the
PrimeDream human silhouette in all four directions. Where a side view omits the
far hand, it uses a mirrored frame from the same hand. Narrow donor frames were
fitted using only colors from the source sprites. The leg bases derive from
icons/mob/human/bodyparts_greyscale.dmi in this repository, with the foot pixels
removed so each prosthetic foot can be drawn separately.

ipc_cosmetic_extremities.dmi uses the same nine original Paradise files listed
above. Original hand frames are retained in all four directions. Feet retain
their native horizontal profiles and palette, with their heights fitted to
rows 29-31 for the common IPC ankle. The top ankle row is bridged with the
original edge colors where needed to join all supported chassis.
