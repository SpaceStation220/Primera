# Звуки Мнемонического архива

Все семь сигналов созданы процедурным синтезом для Primera. Использованы синусоидальные генераторы, огибающие и панорамирование. Авторы — участники проекта Primera. На звуки распространяется [лицензия ресурсов проекта CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

| Файл | Назначение |
| --- | --- |
| humanity_relay.wav | Тихий одиночный щелчок реле |
| humanity_echo.wav | Двойной тик при расхождении |
| humanity_pulse.wav | Короткий обрыв низкого импульса |
| humanity_saccade.ogg | Пять стереощелчков синхронно с движениями глаз, последний сопровождается низким затуханием |
| humanity_ambient.ogg | Двенадцатисекундная петля тихого синтетического гула |
| humanity_settle.ogg | Мягкий нисходящий сигнал при восстановлении |
| humanity_archive_iv.ogg | Двойной щелчок открываемой фрагментированной записи |

jaws_engage.mp3 и jaws_heartbeat.mp3 предоставлены автором изменений. Автор подтвердил распространение по лицензии ресурсов проекта CC BY-SA 3.0.
