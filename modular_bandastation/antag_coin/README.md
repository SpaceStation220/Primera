# Антаг коин

Кнопка в конце раундстартовых антагонистов PreferencesMenu. Активный tier 5 из
SS Central даёт персональное место выбранного события после одобрения R_ADMIN
за 30 секунд. Учитывается raw donator_level, без host/localhost льгот.

Требуется применить `SQL/bandastation/antag_coin.sql` к игровой базе.
Для базы с префиксом имён таблиц заменить имена таблиц на
`<feedback_tableprefix>antag_coin_accounts` и `<feedback_tableprefix>schema_revision_220`.
Миграция повышает версию BandaStation до 1.4. Значение `serversqlname` и порт
должны однозначно определять игровой сервер при восстановлении после рестарта.
Свежие установки также получают таблицу из bandastation_update.sql.

SQL хранит единственную возможность по ckey. Условный UPDATE защищает расход
между серверами. Срок вычисляется в SQL: approval + 604800 секунд; пропущенные
недели и новая подписка его не сбрасывают. При недоступном SS Central/SQL активация
запрещается. Возврат/подтверждение повторяются по request_id при временном сбое БД.
Нажатие заново проверяет tier, поэтому покупка или повышение подписки во время
игры не требуют переподключения. После оплаченного approval последующее истечение
подписки не отменяет забронированную роль; новая активация требует активного tier 5.

Один approval на попытку старта. Резерв занимает одно обычное место до жеребьёвки
остальных кандидатов. Только выбранное стартовое событие; обычный midround и
приоритеты подписок на оставшихся местах сохраняются. Spies не входит в allowlist.
Revolution штатно выдаёт Dormant Head Revolutionary и раскрывает роль через 7 минут;
перед стартом дополнительно проверяется наличие двух глав отделов.

При неудавшейся подготовке роль/очередь/ограничения профессий и Dynamic-состояние
откатываются, коин возвращается, начинается полный lobby_countdown. Повторной
автоматической заявки нет; нужна новая проверка и approval. При уже начавшемся
раунде выход игрока не является основанием для возврата.

Граница автоматического отката — подготовка до создания персонажей. Штатный
PostSetup выдаёт антагонистические datums после перехода в PLAYING. Если он
завершился без исключения, но роль отсутствует, модуль вернёт коин и уведомит
администрацию. Неперехваченный runtime внутри самого PostSetup требует ручного
вмешательства; автоматический откат уже созданного мира не выполняется. Все штатные отказы
по кандидатам, минимуму команды и профессиям проверяются до этой границы.

Проверки находятся в `tests/antag_coin_tests.dm`; они используют native selection
и контролируемое хранилище для гонок/таймаутов. Подключение к реальному SS Central
и миграция рабочей серверной базы не выполняются тестами.

`tests/store_sql_smoke.py` проверяет запросы из `code/store.dm` на отдельной
MariaDB в локальном Docker (Linux), без рабочей серверной базы. После запуска
контейнера `codex-antag-coin-db` с пустой базой `antag_coin_test` выполнить:
`python3 -B modular_bandastation/antag_coin/tests/store_sql_smoke.py`.
