# Значки способностей зомби

Оригинальный набор подготовлен для этого модуля из утверждённых рисунков: десять классовых способностей и общие когти. Каждый кадр — 32×32, одно направление, без анимации. При уменьшении использован nearest-neighbor, чтобы сохранить чёткие пиксельные края.

Состояния: `tongue`, `dash`, `charge`, `pounce`, `pin`, `tear_wall`, `bile`, `acid`, `explode`, `vomit`, `claws`.

Общий фон и рамка уже включены в кадры `abilities.dmi`. У использующих их действий отключена штатная подложка кнопки. Индикация выбранной способности, недоступности и времени перезарядки остаётся штатной.
