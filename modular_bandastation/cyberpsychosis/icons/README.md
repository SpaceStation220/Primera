# Cyberpsychopath sprites

`cyberpsychopath.dmi` contains two single-frame 32×32 states:

- `implant`: red CNS-inspired physical implant. The design derives from the existing `brain_implant_rebooter` state in `icons/obj/medical/organs/organs.dmi` (/tg/station contributors), recolored in a concept approved by the local server owner.
- `action`: red grinning skull with red lightning. New artwork from the concept approved by the local server owner for Cyberpsychopath.

Both approved concepts were converted to native icon size with nearest-neighbor sampling and binary transparency. The source CNS sprite remains unchanged. The injector retains the standard implanter sprite.
